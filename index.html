WORK 02 / WEB APPLICATION

55Bikeni
運動記録・振り返りWebアプリ

スマートフォンやPCから運動を記録し、月ごとの成果を振り返るWebアプリです。時間・距離・消費カロリーの入力から、参考画像の保存、月間目標の管理、CSV出力まで対応しています。

必要な項目だけを入力できる画面と、グラフやカレンダーで記録を確認できる仕組みを作りました。

HTML / CSSJavaScriptCloudflareSupabaseスマートフォン対応
  • 運動記録の登録・編集・削除
  • 参考画像の保存
  • 月間目標と達成率
  • グラフ・カレンダー
  • CSV出力
  • ログイン・クラウド保存
サンプルを試す（別タブ）

ログイン不要。サンプルの変更は画面内のみで、再読み込みすると元に戻ります。通常モードは登録済みアカウントで利用する個人用アプリです。
